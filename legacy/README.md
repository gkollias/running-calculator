# Legacy site

This is the pre-redesign vanilla-JS running calculator site, preserved here for one release cycle while the React/Vite redesign at the repo root stabilizes.

Once the redesign has been on production for at least one release without regressions and any inbound links have been redirected (see `vercel.json` / `vercel.ts` at the root), this folder will be deleted.

Do not modify files here — bug fixes belong in the new React codebase under `src/`.

See `docs/2026-05-16-react-redesign-plan.md` at the repo root for the migration plan.
